# ScintyImage

**Программное обеспечение для анализа и обработки мультимодальных медицинских изображений**

> Рабочий проект. Язык реализации: Python.

## Статус проекта

🟡 Проектирование архитектуры

---

## Описание

ScintyImage — десктопное приложение на Python для научно-исследовательского анализа мультимодальных медицинских изображений (CT, MRI, PET, SPECT и др.), включая 3D/4D данные и мультимодальное совмещение (fusion).

## Ключевые возможности (планируемые)

- Загрузка и просмотр DICOM, NIfTI
- Мультипланарная реконструкция (MPR): аксиальная, сагиттальная, фронтальная
- Интерактивные зоны интереса (ROI): эллипс, прямоугольник, полигон, объёмный ROI
- Измерения: расстояния, углы, площади, объёмы
- AI-сегментация (TotalSegmentator, nnU-Net, SAM2) через единый интерфейс
- Мультимодальное совмещение изображений (image fusion / registration)
- Клинические подпрограммы как подключаемые модули (plugins)
- Пакетная обработка когорт пациентов
- Экспорт результатов в CSV / JSON / DICOM-SR

## Технологический стек

| Назначение | Библиотека |
|---|---|
| GUI | PySide6 (Qt6) |
| DICOM I/O | pydicom |
| Обработка объёмов | SimpleITK / ITK |
| 3D-визуализация, MPR | VTK |
| 2D-просмотр, ROI | pyqtgraph |
| Сегментация | scikit-image |
| AI-модели | PyTorch / ONNX |
| База данных | SQLite + SQLAlchemy |

## Архитектура

```
scintyimage/
├── core/
│   ├── model/        # Patient, Study, Series, ROI, Measurement
│   ├── io/           # DICOM, NIfTI, анонимизация
│   ├── processing/   # фильтрация, регистрация, сегментация
│   └── plugins/      # интерфейс клинических модулей
├── gui/
│   ├── tabs/         # DataTab, ImageTab, ClinicalTabs
│   ├── widgets/      # Viewer, ROI-панель, гистограмма
│   └── windows/      # MainWindow, DetachedWindow
└── app.py            # точка входа
```
